↪ AUTO RECALL · BAIL TO

When a preset goes to Program with TAKE or CUT, its bail-to preset is recalled to Preview once the transition is done — ready for the next TAKE. It never takes by itself. Which one: the preset's own setting, else its group, else the show default — all only while the switch is ON.

THIS PRESET

GROUPS presets (or destinations) that share a bail-to preset and an ON / OFF; the first matching group wins

SAVE

Saves the show to the show library — every desk's presets, tile layouts, auto recall and settings (same as SHOW → SAVE).

Startup-state save (SRsv) follows the atem-connection encoding and is not yet verified on hardware.

DESK ZERO?

Every audio input and the master go back to their defaults: faders 0 dB, gain 0 dB, balance centre, EQ off and flat, make-up 0, dynamics (expander, compressor, limiter) reset.

On / off / AFV, routing, delay, monitor and solo are not changed. This cannot be undone.
