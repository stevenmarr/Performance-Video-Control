# On the deck

Every Control Center page on the Stream Deck + XL has the same four zones: NAV on the left, TARGET along the top, FUNCTIONS in the middle, and STATUS on the right.

## Do it

1. HOME returns to the HOME page. SYSTEM's short press opens the page-set chooser.
2. Hold SYSTEM for 800 ms to enter deck help mode, then press any key. The strip tells you what that key does, and the key sends nothing. Press SYSTEM again to leave.
3. A refused press flashes amber. The reason shows on LINK for a few seconds.
