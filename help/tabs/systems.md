# SYSTEMS

The left list is every kind of system Control Center can run. **On the desk** is what this show is actually using. Drag one onto the desk, or press ADD, then give it a name and IP.

## Do it

1. Drag ATEM, PTZ, or another system onto the desk.
2. Add the same type twice for ATEM A and ATEM B — each has its own name and IP.
3. Right-click a card to rename, duplicate, disconnect, or delete.
