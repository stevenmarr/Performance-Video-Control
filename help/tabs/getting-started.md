# Getting started

Control Center is the one desk for your switchers, cameras, and playback. A show file remembers the desk. APP LINK is how a browser on the network finds this copy of the app.

## Do it

1. Open Control Center (mock mode is fine while you learn — nothing is sent to a real device).
2. Open **HELP** in the header, or press F1, and pick **Tour**. The tour never starts by itself.
3. Drag a system onto the desk and give it a name and IP.
4. Open **SURFACES** to lay out the Stream Deck + XL. Edits go live on the deck right away.
