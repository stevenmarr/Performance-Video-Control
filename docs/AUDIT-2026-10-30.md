# Control Center audit (2026-10-30)

Audited `performance-video-control` at `340d885` (Control Center 0.4), then rechecked after the fixes in this branch.

How it was checked:

- `node server.js --mock --host 127.0.0.1 --port 8791` (UniFi’s ports 8080 and 11002 were not used).
- Playwright Chromium at 1920×1080 clicked every top tab (SYSTEMS, each system’s pages, SCOPES, CUES, PRESETS, Control Devices) and the ATEM, PTZ, Pixera, and Millumin pages. A 1280×800 pass checked the header.
- The browser reported no page errors and no failed `/api/` responses on that pass.
- Static pass over button ids, client `fetch` paths, and the route table in `lib/server.js`.

Severity is what an operator would hit on a show. “Fixed” means this branch changes it. Everything else is a recommendation.

## Findings

| Sev | Location | What's wrong | Suggested fix | Status |
|---|---|---|---|---|
| High | `public/index.html:524` (was after `</main>`, beside the log) | PRESETS (`#pane-looks`) and CUES (`#pane-cues`) were not inside `<main>`. `main` is `flex: 1` and `body` is `overflow: hidden`, so those pages were crushed into a strip under a blank pane and the log. A preset, cue, or macro name with those characters broke the markup. Master-cue palette items put JSON in `data-item` without escaping quotes, so a drag did not carry the item. Macro XML with `&` was not well-formed. | Escape to `&amp;`, `&lt;`, `&gt;`, `&quot;`. | Fixed |

| Low | `public/style.css` (`.ad-op`) | On ATEM MACROS → OPERATOR, LOOP STEPS and PLAY STEPS were one cell in the macro grid, so they sat in the tile row. | `grid-column: 1 / -1` so they take the next row. | Fixed |

### Run the tests on a Mac

Node 18 or newer (the app itself still runs on Node 16; CI uses Node 22). From the repo:

```bash
npm install
npm test
```

That is the unit suite, the story checklist, and the audit regressions. It does not need a browser. UI files under `test/ui-*.test.js` skip when Playwright is not installed.

The browser smoke test:

```bash
npm install --no-save playwright@1.56.1
npx playwright install chromium
npm run test:ui
```

`npm install --no-save` keeps Playwright out of `package.json`. If it is left in `node_modules`, a later `npm test` also runs the older Playwright files, and several of those fail (see the recommendation above). Remove `node_modules/playwright` after the smoke test, or run `npm test` first.

The suite does not open port 8080 or 11002. Servers in the tests bind an ephemeral port on `127.0.0.1`. Hardware is the built-in mocks (`MockAquilon`, `MockE2`, `MockPixelHue`, `MockAtem`, `MockPTZ`).

To run only the story checklist:

```bash
node --test test/stories.test.js
```

Skipped tests print the reason. They are the acceptance list for the stories that are not done yet.
